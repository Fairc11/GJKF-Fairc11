# Windows 打包与分发

## 推荐结构

Python 桌面工具优先使用 PyInstaller onedir，再按需要使用 Inno Setup 输出安装器。onefile 只有在启动速度、临时解压、杀毒误报、日志和依赖路径均验证后才采用。

## 运行时路径

- 安装目录视为只读。
- 日志、缓存、数据库和临时下载写入 `%LOCALAPPDATA%\项目名` 或项目明确的用户目录。
- 登录 Cookie 文件若是历史兼容例外，必须在文档和清理流程中单独说明。
- 不依赖启动 CWD。

## 常见门禁

- `console=False` 时处理 `sys.stdout`/`sys.stderr` 为 `None`。
- Windows 终端可能使用 GBK，用户可见输出避免编码崩溃。
- hidden imports、动态模块、模板、静态文件和浏览器二进制进入 onedir。
- WebView2 检测覆盖实际支持的注册表视图和安装目录，不猜键名。
- 卸载时明确保留或清理用户数据，不静默删除用户产物。

## 验收

1. 从安装器全新安装，不从源码目录启动。
2. 验证普通用户权限、路径含空格和中文用户名。
3. 验证 WebView2 缺失或过旧时的中文提示。
4. 使用 Windows Sandbox、虚拟机或另一台机器完成核心流程。
5. 从用户数据目录收集日志，不要求用户只压缩安装目录。
