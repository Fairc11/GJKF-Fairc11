# 账号、隐私与数据隔离

## 数据清单

对每种数据记录：创建者、默认路径、权限、生命周期、是否进入 Git、是否进入包、是否允许迁移、清理方式。

重点检查：

- Cookie 文件、token、OAuth 凭据；
- WKWebView、WebView2、Chromium profile 和站点数据；
- 日志、缓存、数据库、任务状态；
- 用户导出的正文、媒体、缩略图和索引；
- `.env`、本地配置、测试夹具和截图；
- handoff 中的个人绝对路径、账号标识、真实档案统计和校验值。

## 四层审计

### Git

检查当前已跟踪文件、待提交缓存区和必要的历史范围。`.gitignore` 只能阻止未来新增，不能证明历史安全。

### 构建配置

逐项读取 PyInstaller `datas`、资源复制脚本、DMG/安装器输入目录。禁止打包用户主目录、运行时目录或宽泛的项目根目录。

### 真实产物

挂载 DMG、展开 `.app`、检查 onedir 或安装器解包结果。搜索敏感文件名、个人绝对路径和用户产物；必要时比较包内资源与源码哈希。

### 发布资产

检查准备上传的源码包、DMG、EXE、zip、校验文件和 Release notes。源码安全不代表二进制安全，反之亦然。

## 声明边界

- 只有四层证据充分时，才能说“分发包不包含制作者登录信息”。
- 文件权限为 `0600` 不等于内容已加密。
- 不知道 WebView 物理目录时，只声明使用系统持久化数据存储，不猜路径。
- 用户档案允许迁移时，登录数据仍应独立，换机后重新登录。
